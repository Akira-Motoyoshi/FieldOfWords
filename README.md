# FieldOfWords ― 言葉で育つ、SNS対抗の庭

古橋研究室 11月 Muse 自動化ハッカソン（Issue #42）のプロジェクト。
ライセンス: CC BY 4.0 / 発表: 2026-11-24（火）ゼミ

## 企画概要

SNSごとに「架空の庭」を1つ作り、その媒体の住人の反応だけで育てる参加型の連載。
最初は全ての庭が「土だけ」の状態から始まり、毎日の投稿（1日1件/媒体）で様子を報告する。

- インプレッション = 日光
- いいね = 水
- ポジティブな言葉のコメント = 栄養（花が育つ）
- チクチク言葉のコメント = 健康度が下がり枯れる方向に傾く（即死はなく、回復可能）
- リポスト/シェア/新規フォロワー = 新しい種

庭は媒体別に独立していて、毎日、全庭の生育と順位を発表して競わせる
「SNS対抗・庭リーグ」形式。

## 対象媒体（確定）

| 媒体 | 投稿経路 | 反応の収集 |
|---|---|---|
| X | Buffer（無料プラン、API課金回避） | Buffer Insights |
| Instagram | Muse コネクタ（予約投稿） | コネクタ |
| Threads | Muse コネクタ | コネクタ |

Bluesky / Misskey は検討の結果、対象外（経緯は PLAN.md）。

## 投稿ルール

- 1日1件/媒体。内容は「その日の庭の様子＋リーグ順位」のみ
- 締切コール等の煽り投稿はしない
- コメントの言葉判定（優しい/チクチク/中立）は Muse が行い、件数を公開する
- チクチク言葉の投稿者を名指ししない

## 構成

- `PLAN.md` ― 設計書（決定事項・実行構成・毎日のプロセス）
- `garden/state.json` ― 庭の状態（唯一の正本。媒体別に day/日光/水/栄養/健康度/ステージ）
- `garden/` ― Day 0 の庭画像（開始状態。画像はローカル管理）
- `scripts/post_all.py` ― Bluesky/Misskey 投稿スクリプト（検討時の参考実装）

## 毎日のプロセス（自動実行）

毎朝、Muse が cron で: 前日分の反応を収集 → 言葉を判定 → 全庭の状態を更新 →
媒体ごとに庭画像を生成 → 投稿文を作成 → 各経路で投稿 → Permalink を記録 → 報告。

## スケジュール

- 2026-11-21: Day 0 開始（3媒体で初回投稿）
- 2026-11-22: Day 1 / 2026-11-23: Day 2（公開投稿3件が揃う）
- 2026-11-23〜24: Medium 記事（スクショ＋Permalink）作成
- 2026-11-24: ゼミで発表（1分目標）
