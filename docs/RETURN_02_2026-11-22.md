- 48×48、2フレーム。**紫の毛羽立った塊**に、蛍光ライムの斑点（フレームごとに1×1と2×2が入れ替わって脈打つ）、骨色の目、牙。頭上に胞子が漂う。f2 は、まばたきと、胞子の移動。

- `compose.py` は、毒花が3輪以上の日に、あふれた分を `flower_mold` 1つにまとめ、**後列**に置く（既存の動作）。素材が入ったので、`report.json` の `missing` から消える。
- 見た目の確認: 茶色の土と、Threads の暗い紫の空の両方で、毒花（ラフレシア）と並べて確認済み。

### `compose.py` の拡張仕様（採用）

**state の読み取り**
| フィールド | 動作 |
|---|---|
| `milestones.rainbow`（真偽） | `true` なら、虹を描く。**数値（リポスト10件）は、司令塔が判定してフラグを立てる**。`compose.py` は、フラグだけを見る |
| `milestones.butterfly`（真偽） | `true` なら、蝶A・Bを描く。**数値（リポスト20件）は、同様に司令塔側** |
| `events_today.milestones`（リスト。省略可） | `["rainbow"]` や `["butterfly"]`。**達成した日だけ**、その演出のまわりに白いキラキラの粒を足す（コードで描画。素材は不要） |

虹と蝶は、**一度立てたフラグが `true` のあいだ、毎日描かれる**。両方 `true` でもよい。

**描画の位置と順序**
- 虹: 下端中央を (90, 47) に合わせる（72×36。柵の上端から立ち上がり、y 13〜47、x 54〜126）。**背景・柵・花壇の上、花の下**に重ねる。左上の「DAY」と中央の庭名の帯（y 3〜11）、右上の太陽には、重ならない。
- 蝶: 中心を、6か所の候補から**日付で選ぶ**。蝶Aと蝶Bは、同じ位置にならない（`day*2 + k*3` を6で割った余り）。**日が変わると、位置が変わる**。**花の前**（最前面）に描く。候補: (30,58) (156,62) (100,54) (50,86) (132,92) (88,72)。
- 素材ファイルがなければ、その演出だけ描かずに続行し、`report.json` の `missing` に `fx_rainbow` などと出る（画像は必ず出る）。

**そのほか**
- alt 下書き（`<媒体>.alt.txt`）に、「空に虹がかかっている。」「蝶が舞っている。」が入る。
- `report.json` の各庭に、`effects: {"rainbow": 真偽, "butterfly": 真偽}` が増える。

**数値（10・20）は仮置きのまま**です。確定したことにしていません。`make_post.py` の `MILESTONES` も、同じ仮置きです。

## 7. 依頼5：庭師（Muse）

- `gardener_idle`: 立ち姿（f2 で、まばたきと1px の上下）
