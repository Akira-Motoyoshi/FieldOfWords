## 3. 花と毒花【確定／ビジュアル詳細は暫定】

### 良い花（ふわふわ言葉の種類で品種が決まる）

| コメントの傾向 | 花 |
|---|---|
| 応援・励まし・存在の肯定以外の前向き | ひまわり |
| 感謝 | さくら草 |
| 面白い・笑い | チューリップ |
| 褒め・すごい | 金の薔薇（レア） |
| 絵文字のみ・短い好意・存在の肯定（「見てますよ」） | 野の花 |

成長段階: 芽 → 茎 → 蕾 → 開花（芽・茎は共通、蕾・開花は品種別）

### 毒花（初期5種）

| チクチクの傾向 | 毒花 | 浄化後 |
|---|---|---|
| 悪口・罵倒 | ラフレシア | 巨大な金の薔薇 |
| 嫌味・皮肉 | ハエトリソウ | 笑顔のひまわり |
| 批判・ダメ出し（辛口の断定的なもの） | サボテン | ピンクの満開サボテン |
| 煽り・攻撃的 | チリペッパー花 | たいようガーベラ |
| 重い悪意（庭への悪意まで） | ブラックホール花 | 星の花 |

- 画像に描く毒花は**1日2輪まで**。超過分は「ナゾのカビ園」（紫×ライムの斑点カビ）1区画にまとめる。
- 追加候補（今は使わない）: ヒトクイバナ、ドクキノコ、灰色のしおれ花、ヘナチョコ草、ながながヅタ。

### 8bit ビジュアル共通ルール【暫定：試作画像で確認後に確定】

| | 良い花 | 毒花 |
|---|---|---|
| 色 | 暖色・明るい黄/ピンク/白/空色 | 紫・どす黒い赤・ドブ緑・黒。蛍光は**ライムとピンクの2色のみ** |
| 縁取り | 明るい縁 | 黒＋紫の太い縁 |
| 形 | 丸い花びら・左右対称 | ギザギザ・非対称・ドクロ/目/牙のどれか1つ必須 |
| 動き | 揺れる・光が瞬く | ガス・目・口など不穏な動き |
| 背景 | 水色の空・光の粒 | 紫がかった暗い空・ガスの粒 |

- 空: 毒花の生存数 0=水色 / 1〜2=薄紫 / 3〜4=紫 / 5以上=暗い紫＋稲妻風ドット
- 画像仕様: ネイティブ180×180、×6最近傍拡大で1080×1080、全媒体正方形。花スプライト32×32（大型48×48）。庭は5列×3行、最大15区画。
- 媒体別の柵（ロゴは使わない）: X=黒い鉄柵・モノクロ / Instagram=夕焼け木柵・ピンク花壇縁 / Threads=白い柵（黒い角）・明るい芝
- 素材は透過PNG、命名は `flower_good_himawari_bloom_f1.png` の形式。合計約85枚（試作は ラフレシア→金の薔薇 の1ペアから）。

## 5. 言葉の判定ルール【確定】

### 優先順位

**集計外 > 対象外 > チクチク／ふわふわ > 中立**。1コメントにつき判定は1つ。迷ったら中立。

### 集計外（花にも健康度にも反映しない）

| 種類 | 扱い |
|---|---|
| 差別（属性への攻撃） | 集計外 |
| 脅迫 | 集計外 |
| 個人攻撃（運営者・特定個人への攻撃） | 集計外 |
| 自傷を促す言葉 | 集計外。**`alerts_for_owner` に種別と日付だけを記録し、ユーザーに報告して人が判断する** |
| 庭への悪口に上記が混在 | 集計外（安全側に倒す） |

- 原文は投稿にも記録にも載せない。運営用記録は「集計外◯件」のみ。通報機能の使用は人が判断する。

### 対象の限定

判定対象は**この庭・花・画像・順位・リーグ・庭の世話（Muse）に向けられた言葉のみ**。他のコメント投稿者宛の発言、運営者個人・第三者への言及、無関係な話題は「対象外」。

### 間接表現

字面ではなく意味と意図で判定する（例: 「そのお花、咲いているうちはきれいだね」→ チクチク（嫌味）／「明日も見に来ようかな」→ ふわふわ）。

### 安全装置

- confidence は high / mid / low。**low は中立に落とす**。
- 好意的に読める余地があればチクチクにしない。
- 「笑」「w」「🙂」だけで好意と判定しない。
- 皮肉検出を嫌味側に偏らせない（善意に毒花を出すと炎上するため）。
- 日本語以外は原則中立（読める場合のみ判定）。
- 辛口の断定的ダメ出し → チクチク（サボテン）／敬意ある改善提案 → 中立。
- 「毎日よく続くねえ（笑）」「絵は好きだけど更新頻度が鬱陶しい」→ 中立。

### 判定の出力形式（1コメントごと）

| 項目 | 値 |
|---|---|
| target | garden / other |
| exclusion | none / discrimination / threat / personal_attack / self_harm |
| tone | soft / prickly / neutral |
| type | 応援・感謝・面白い・褒め・存在 ／ 悪口・嫌味・批判・煽り・重い悪意 |
| confidence | high / mid / low |

### 公開の仕方

- 毎日の投稿に **ふわふわ◯件／チクチク◯件／中立◯件／集計外◯件** を載せる。
- 代表例・原文は載せない。種類名（嫌味など）と件数だけ。
- チクチクの投稿者は名指ししない。

### テスト合格基準（Day 1 の判定開始＝11/22朝までに実施）

| 観点 | 基準 |
|---|---|
| 集計外の見逃し | 0件 |
| 善意への毒花の誤判定 | 0件 |
| 全体の一致率 | 85%以上 |
| 19番・23番相当（好意とも冷笑とも読める／好意と批判の混在） | 中立なら合格 |

テスト例文集（32件、架空）は別途 `judge_testset.md` として渡す予定（次回の引き継ぎ #02）。
